## 自动化覆盖

- 报告 ID 与 payload 的边界、编号/无编号 Input Report、同步/异步 Output/Feature Report 接口；同步发送复用已编码缓冲区时仍只补入一次 ID，返回字节数不含 ID。
- 连接代次、路径复用、身份变更时先移除后添加、元数据变化、筛选器成员变化。
- 多配置之间 OR、组内字段 AND、VID/PID 保持配对；混合 HID / SERIAL / USB Print、空集合、默认单配置；同步/异步发现和监听、重叠配置去重及跨配置的事件成员变化。
- 相同 VID/PID/序列号的多个 HID endpoint 按 Usage Page/Usage 配对筛选，覆盖单配置、多配置、快照和热插拔；字段可单独指定、零值精确匹配、排除无 HID 元数据的接口。
- 初始快照与事件溢出提示。
- 小容量传输中的部分读写、全双工和接收背压；64 个会话同时使用共享运行时。
- 接收超时后继续读取、写入超时后继续使用、无限超时写入被取消后继续处理命令。
- 写入阻塞与接收等待时关闭、重复关闭、最后一个克隆释放、模拟原生移除、EOF 错误。
- 同步/异步接口复用以及 Tokio 上下文中的阻塞调用拒绝。
- 大小、队列容量和超时参数的非法值。
- USB Print 的参考 PTB 路径/父节点 VID/PID 解析、筛选、重插代次；0/63/64/65/128 字节 ZLP 边界及包大小/禁用选项。
- Windows USB Print 使用与正式代码相同的重叠 I/O 引擎，在本地命名管道上验证读写完成和取消回收；非 Windows 打开返回 `Unsupported`。

内存传输验证状态机和并发行为，不代表串口驱动或 HID 后端已经通过硬件验证。

## 实机验收矩阵

三个系统分别准备一个支持编号 Report / Feature Report 的测试 HID、一个无编号 HID，以及串口回环或回显设备。按设备协议提供正确报告长度，不默认 64 字节。

| 场景 | 验收行为 |
|---|---|
| 管理器启动时插拔、通信中拔出 | 不挂起；观察到设备列表变化，正在等待的操作返回终态错误 |
| 同一设备反复插拔、相同路径换设备 | 观察到移除后旧代次失效，新连接重新打开；不自动重发数据 |
| 复合设备、同 VID/PID 多个接口 | 不合并接口；通过路径/Usage/序列号精确选择 |
| USB、板载、蓝牙、虚拟串口 | 所有已被系统枚举的端口可发现；通知缺失时由校准枚举补齐 |
| 非法波特率、流控、DTR/RTS、占用、权限不足 | 返回错误并保留底层原因；确认驱动配置是否部分应用 |
| 有/无 Report ID、Feature Report、不同报告长度 | 上下层只添加/剥离一次 ID，payload 与实际协议一致 |
| 事件消费速度不足、数据消费速度不足 | 事件溢出要求重建快照；数据内存有界，不承诺设备端缓冲不丢失 |
| 打开/关闭循环、阻塞 HID 控制请求 | 检查句柄和线程最终释放，记录不能取消的底层调用耗时 |
| PTB USB Print（36B0:5320） | 使用 usbprint.sys 驱动，确认接口枚举和父节点标识；按协议发送 63/64/65/128 字节帧，确认整包后的 ZLP 和设备响应 |
| USB Print 通信中拔出、命令超时和关闭 | 观察断开事件，取消并回收读写请求；记录实际驱动的取消延迟 |

## 性能测量方法

串口使用 `cargo run --release --example serial_loopback -- 30 921600 <port> [<port> ...]`。
它需要物理回环或回显程序，会发送测试数据。输出每个端口的有效接收吞吐与 1024 字节请求的往返延迟 P95/P99；其中包含线路传输、驱动缓冲和回显延迟，不是纯库调用开销。

分别测量 1、16、64、100 个端口；测试 HID 时按固件协议编写报告发生器，分别测量 1、16、64、100 个会话。每种规模运行 30 分钟，并另外执行至少 100 次打开/关闭与插拔循环。

记录 OS、驱动、固件、USB 拓扑、串口参数、报告大小、实际收到的数据量、吞吐、P95/P99、CPU、RSS、句柄数、线程数、关闭耗时。进程 PID 由回环示例输出；资源数据使用系统性能工具采集。

热插拔延迟从系统接口可用通知到库发出对应事件计时，并另测物理插入到接口可用的驱动延迟。当前默认事件合并 40 ms，节点准备时间及枚举成本不计入任何硬性承诺。没有实测依据前，不给出固定设备数量或吞吐保证。
